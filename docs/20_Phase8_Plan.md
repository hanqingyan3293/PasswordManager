# Phase 8 Plan: Basic Extraction

状态：执行中

## 1. 目标

实现用户确认后的单个压缩包基础解压。

## 2. 本阶段要做

- 新增 `ExtractService`。
- 固定调用 exe 相对目录下的 `tools/7zip/7z.exe`。
- 使用已保存的成功密码解压。
- 历史记录页新增“解压”按钮。
- 用户必须选择输出目录。
- 新增 `extract_logs` 表。
- 记录解压成功/失败日志。
- 新增真实 7-Zip 解压测试。

## 3. 本阶段不做

- 不自动批量解压。
- 不做解压任务队列。
- 不做暂停/继续。
- 不做右键菜单。
- 不做 GPU 加速。

## 4. 验收标准

- CMake 配置成功。
- Ninja 编译成功。
- 自动化测试通过。
- 正确密码可解压测试压缩包。
- 错误密码返回失败。
- 程序能启动和关闭。
