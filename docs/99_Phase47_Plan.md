# Phase 47 Plan - Feature-Level Settings

## 目标

新增设置页功能级开关，让智能匹配候选来源和右键菜单功能项可控，并保存到便携目录配置文件。

## 范围

- 新增本地配置文件：`config/settings.ini`。
- 智能匹配设置：
  - 当前压缩包历史优先。
  - 同目录历史候选。
  - 密码库候选。
  - 同目录说明文件候选。
  - 最大候选数。
  - 说明文件最大候选数。
  - 单个说明文件读取上限。
- 右键菜单功能项设置：
  - 压缩包右键各功能项。
  - 文件夹右键各功能项。
  - 普通文件右键打包功能项。

## 生效规则

- 智能匹配设置保存后立即生效。
- 右键菜单功能项保存后，需要执行 `重新安装/修复` 才会重写注册表菜单。

## 不做

- 不改变数据库结构。
- 不做账号/同步。
- 不实现 GPU 或多线程加速。
- 不做复杂设置导入导出。
