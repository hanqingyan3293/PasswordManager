# Phase 52 Plan：UI 基础修复

## 目标

在进入 QML 混合架构前，先修复现有 Widgets UI 的基础显示问题，尤其是数字列显示像符号的问题。

## 范围

- 固定应用全局字体。
- 表格使用稳定中文字体和数字字体。
- 数字单元格右对齐，减少误读。
- 统一表格行高、表头、网格线、选中颜色。
- 保持现有页面结构和功能不变。

## 不做

- 不引入 QML。
- 不重写页面。
- 不改变数据库、右键菜单、任务队列逻辑。
- 不改变表格分页、复制、列宽拖动行为。

## 验收

- 数字列视觉上显示为正常阿拉伯数字。
- 首页、密码库、历史记录、解压队列表格样式统一。
- 表格仍支持列宽拖动、选择、复制和排序。
- 构建和测试通过。
