# Phase55 纯 Widgets 首页概览计划

日期：2026-08-03

## 目标

在不引入 QML、不增加 Qt Quick 运行依赖的前提下，为首页补回轻量概览能力。

## 范围

- 首页标题下方新增纯 Widgets 概览卡片。
- 显示当前筛选压缩包数、当前页显示数、密码库记录数、待处理任务数。
- 概览随首页刷新、搜索、分页变化同步更新。

## 不做

- 不引入 QML。
- 不改数据库结构。
- 不改扫描、密码测试、智能匹配、右键菜单逻辑。
- 不读取大表做重统计，避免增加首页刷新负担。

## 验收

- Debug/Release 构建通过。
- CTest 全部通过。
- 发布包仍保持纯 Widgets 依赖，不出现 Qt Quick/QML 运行库。
- 首页概览显示正常，搜索、分页和表格列宽拖动不受影响。
