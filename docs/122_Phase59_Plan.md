# Phase59 干净 Windows 环境验收计划

日期：2026-08-08

## 目标

验证 Phase58 轻量包在没有项目源码、Qt、Visual Studio 和预装 VC++ Runtime 假设的 Windows 10/11 x64 环境中，可以独立启动并完成主要工作流。

## 范围

- 生成可复制到普通干净机器的独立验收套件。
- 生成 Windows Sandbox `.wsb` 配置。
- 自动检查正式轻量 ZIP、发布清单、应用本地 VC++ Runtime 和内置 7-Zip。
- 自动生成无密码、正确密码和错误密码测试场景。
- 自动运行 `PasswordManager.exe --smoke-test`。
- Sandbox 中打开主程序和测试目录，供人工验收界面与右键菜单。
- 保存机器信息、自动结果和人工清单。
- 每次验收使用独立会话结果目录，重新准备套件不得删除历史结果。

## 明确不做

- 不自动启用 Windows Sandbox 功能。
- 不修改 BIOS、虚拟化或 Windows 可选功能。
- 不发布新版 Release。
- 不删除图形兼容组件。
- 不开始 GPU 或多线程加速。

## 隔离设计

- Sandbox 输入目录映射为只读。
- 结果目录单独映射为可写。
- Sandbox 网络关闭。
- Sandbox 虚拟 GPU 关闭。
- Sandbox 剪贴板重定向关闭。
- 应用和测试压缩包复制到 Sandbox 用户桌面的临时目录运行，不直接运行宿主机映射目录中的程序。

## 自动验收

- 操作系统为 64 位 Windows。
- 轻量 ZIP SHA256 与 `.sha256` 文件一致。
- ZIP 解压前后不存在预置数据库、配置、日志或备份文件。
- 5 个应用本地 VC++ Runtime DLL 存在且清单哈希正确。
- GUI 进程实际加载的 5 个 VC++ Runtime DLL 均来自程序目录，不依赖 `System32` 中的同名文件。
- `RELEASE_MANIFEST.txt` 所有条目存在且哈希正确。
- 内置 `7z.exe` 可运行。
- 无密码压缩包测试成功。
- 加密压缩包使用正确密码成功、错误密码失败。
- 主程序 smoke-test 成功。
- 中文 Unicode 路径可以创建并由内置 7-Zip 正常处理。

## 人工验收

- 主程序首次打开无现成密码记录。
- 设置页显示内置 7-Zip 可用。
- 7-Zip File Manager 显示中文。
- 扫描、手动密码测试、智能匹配、自动学习、解压正常。
- Windows 资源管理器右键菜单安装、调用、卸载和残留检查正常。
- 记录 SmartScreen、缺失 DLL、界面异常和崩溃情况。

## 完成条件

- 自动结果全部通过。
- 人工清单全部通过或对失败项形成明确缺陷记录。
- Windows 10/11 x64 至少一个干净环境完成验收。
