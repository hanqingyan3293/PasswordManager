# Phase 45 Plan - Local Description Password Candidates

## 目标

实现“本地说明文件提取密码”的第一版，让智能匹配测试除了密码库外，也能读取压缩包同目录的说明文本作为候选密码来源。

## 范围

- 只读取本地文件，不联网，不调用 AI。
- 只处理压缩包同目录的说明文件。
- 支持 `.txt`、`.md`、`.nfo`、`.url`。
- 优先读取与压缩包同名的说明文件，其次读取文件名包含 `readme`、`password`、`pass`、`pwd`、`密码`、`说明`、`解压`、`提取` 的说明文件。
- 单个说明文件最大读取 256 KB。
- 每个压缩包最多提取 20 个说明文件候选。

## 密码规则

第一版只解析明确格式：

```text
密码：123456
解压密码: 123456
压缩包密码 = 123456
password: 123456
pass = 123456
pwd: 123456
```

## 优先级

按照当前项目书优先级，说明文件候选排在密码库候选之后：

1. 密码库候选
2. 同目录说明文件候选

如果候选重复，只保留第一次出现的密码。

## 不做

- 不扫描压缩包内部说明文件。
- 不递归扫描子目录说明文件。
- 不做模糊语义理解。
- 不把说明文件里的密码直接写入密码库。
- 不改变右键菜单结构。
