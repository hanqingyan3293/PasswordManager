# User Manual

## 启动

正式使用运行：

```text
out/PasswordManager-portable/PasswordManager.exe
```

用户数据保存在便携目录下的 `data/`，密码当前按已确认方案明文保存到本地 SQLite。

## 密码库

- `新增`：添加明文密码记录。
- `编辑`：修改选中的密码记录。
- `删除`：删除选中的密码记录。
- `复制单元格`：复制当前格，特别适合复制密码格。
- `复制整行`：复制当前行。
- `导入 CSV` / `导出 CSV`：使用 UTF-8 CSV，内容包含明文密码。

CSV 格式：

```text
password,category,note,favorite,success_count,failure_count
```

## 首页扫描与测试

- `扫描文件`：选择一个或多个压缩包。
- `扫描文件夹`：递归扫描文件夹。
- 支持 ZIP、RAR、7Z。
- `测试密码`：先输入密码，再测试选中压缩包。
- 密码框留空时，可确认后测试无密码压缩包。
- `智能匹配测试`：可多选压缩包，批量使用密码库候选和压缩包同目录说明文件候选进行测试。

## 表格

首页、密码库、历史记录、解压队列都支持：

- 空数据时保留表头。
- 列宽拖动调整。
- 点击表头排序，ID 按数字排序。
- 分页：10、20、50、100、200、500、全部。
- 输入页码跳转、上一页、下一页。

## 历史记录与解压

- 历史记录显示压缩包与成功密码的关联。
- 可复制密码、复制整行、查看对应密码库记录、删除历史关联。
- 删除历史不会删除密码库记录。
- 历史记录页内的 `解压` 会要求选择输出目录。

## Windows 资源管理器右键菜单

在 `设置` 中安装、卸载、刷新或 `重新安装/修复` 右键菜单。发布包移动位置后需要重新安装/修复。

压缩包右键：

```text
压缩包密码管理器 >
├── 自动查找密码
├── 使用密码库测试
├── 查看结果
├── 解压
├── 打包压缩包
└── 打开主程序
```

文件夹右键：

```text
压缩包密码管理器 >
├── 扫描文件夹
├── 打包压缩包
└── 打开主程序
```

行为说明：

- `自动查找密码`：只检查该压缩包是否已有成功密码记录，并弹窗提示；无密码压缩包会提示无需密码。
- `使用密码库测试`：打开或调出主程序，把密码库候选和压缩包同目录说明文件候选加入测试队列，不解压；无密码压缩包会跳过，不会记录任意密码。
- `查看结果`：不打开主界面，只弹窗显示该压缩包的成功密码记录，最多显示前 5 条。
- `解压`：默认解压到压缩包同目录的同名文件夹。程序先测试无密码，再测试已知密码，最后要求手动输入密码；测试通过后才真正解压。非空密码解压成功后会写入密码库和历史记录。
- `打包压缩包`：打开本项目内置 `tools/7zip/7zFM.exe`，由用户在 7-Zip 图形界面里选择压缩参数。

同一路径同名压缩包如果被重新创建，程序会通过 quickHash 判断内容是否变化。内容变化后会清理该路径旧压缩包的成功密码关联，避免旧密码显示到新压缩包上。
- `扫描文件夹`：打开主程序并扫描该文件夹。
- `打开主程序`：打开主窗口。

## 设置

- 查看运行目录、数据目录、日志目录、备份目录和内置 7-Zip 状态。
- 打开程序目录、数据目录、备份目录、日志目录、用户手册、测试数据。
- 备份或恢复 SQLite 数据库。
- 导出诊断包。
- 运行性能基准，当前仍是单线程基线；GPU / 多线程加速留作后续专题。

## 测试注意

- 不要直接双击 Debug 测试程序，例如 `PasswordManagerTests.exe`，否则可能弹出缺少 `Qt6Cored.dll`。自动化测试请用 CTest。
- 真实环境测试前建议先备份数据库。
- CSV 导出、数据库文件和诊断包都可能包含明文密码。
## Phase 38 补充：右键菜单覆盖范围

普通文件右键：

```text
压缩包密码管理器 >
└── 打包压缩包
```

文件夹空白处右键：

```text
压缩包密码管理器 >
├── 打包压缩包
└── 打开主程序
```

`打包压缩包` 调用发布目录内置 `tools/7zip/7zFM.exe`，发布包同时携带 `tools/7zip/Lang/zh-cn.txt`。卸载右键菜单会同时清理早期版本可能写入的历史 `PasswordManager` 注册表项；如果右键仍残留失效入口，先在设置页执行 `重新安装/修复`，再执行 `卸载右键菜单`。

## Phase 39 补充：普通文件打包

普通文件右键的 `打包压缩包` 会先进入 PasswordManager 的 `compress-archive` 动作，再打开该文件所在目录的内置 7-Zip File Manager。这样 txt、py、json 等普通文件不会被 7-Zip 误当作压缩包打开。文件夹和压缩包右键打包行为保持不变。

## Phase 40 补充：右键菜单卸载验证

卸载右键菜单后，程序会逐项反查当前和历史 `PasswordManager` 注册表路径。如果仍有残留，设置页会弹窗显示具体残留项；如果没有残留，才提示卸载完成。

## Phase 41 补充：状态刷新只读化

设置页刷新右键菜单状态时，Windows 下使用原生只读注册表查询，不再通过 `QSettings` 读取不存在的 key，避免卸载后又生成 `PasswordManager.*Menu` 空壳注册表项。

## Phase 42 补充：安装状态识别

设置页读取右键菜单状态时，会正确处理 `RegGetValueW()` 长度探测返回 `ERROR_MORE_DATA` 的情况，避免安装成功但状态仍显示未安装或不完整。

## Phase 43 补充：状态读取稳定化

设置页右键菜单状态读取改为先打开注册表 key，再用 `RegQueryValueExW()` 读取值，进一步避免安装后状态被误判为未安装或不完整。

## Phase 44 补充：7-Zip GUI 中文

主程序启动时会设置 `HKCU\Software\7-Zip\Lang = zh-cn`，并要求发布包中存在 `tools/7zip/Lang/zh-cn.txt`。右键打开内置 7-Zip File Manager 时应优先显示中文。

## Phase 45 补充：说明文件密码候选

智能匹配测试会读取压缩包同目录的说明文件作为额外候选来源。第一版只读取 `.txt`、`.md`、`.nfo`、`.url`，优先读取与压缩包同名的说明文件，也会读取文件名包含 `readme`、`password`、`pass`、`pwd`、`密码`、`说明`、`解压`、`提取` 的说明文件。

支持格式示例：

```text
解压密码：123456
密码: 123456
password = 123456
pwd: 123456
```

说明文件候选排在密码库候选之后，不会直接写入密码库。只有实际测试成功后，程序才会按现有成功流程记录密码。

## Phase 46 补充：智能匹配优先级

首页 `智能匹配测试` 和右键 `使用密码库测试` 使用同一套候选顺序：

1. 当前压缩包已知成功密码。
2. 同目录其他压缩包的已知成功密码。
3. 密码库候选，内部按收藏、成功次数、失败次数、更新时间和 ID 排序。
4. 压缩包同目录说明文件候选。

重复密码只保留最靠前来源的一条。分类候选暂未启用，因为压缩包记录当前没有分类字段。

## Phase 47 补充：功能级设置

设置页新增 `智能匹配` 和 `右键菜单功能项`。

智能匹配设置保存后立即生效，可控制：

- 当前压缩包历史优先。
- 同目录历史候选。
- 密码库候选。
- 同目录说明文件候选。
- 最大候选数。
- 说明文件最大候选数。
- 单个说明文件读取上限。

右键菜单功能项保存后，需要在设置页执行 `重新安装/修复`，资源管理器右键菜单才会按新开关重写。

## Phase 48 补充：文件指纹

程序扫描压缩包时会同时保存：

- `quickHash`：快速哈希，用于旧记录兼容和快速变化判断回退。
- `fullHash`：完整文件 SHA256，用于可靠识别同一压缩包。

首页表格中的 `文件指纹` 显示 fullHash 前 16 位。旧数据库会自动新增 `full_hash` 字段，但旧压缩包记录需要重新扫描后才会补全完整指纹。

智能匹配会优先尝试当前压缩包历史，其次尝试同 fullHash 的其他路径成功密码，再进入同目录历史、密码库和说明文件候选。

## Phase 49 补充：补全文件指纹

设置页 `数据备份与恢复` 区域提供 `补全文件指纹`。

该功能会为数据库中 `full_hash` 为空且文件仍存在的压缩包记录计算完整 SHA256。它只更新压缩包记录的文件指纹，不修改密码库、不修改成功历史、不删除文件不存在的记录。

如果旧记录较多或文件较大，补全过程可能需要等待一段时间。

## Phase 50 补充：扫描模式

设置页 `智能匹配` 区域新增 `扫描时计算完整文件指纹`。

- 开启：精确模式。扫描时计算完整 SHA256，`文件指纹` 可直接显示，同 fullHash 历史匹配更可靠。
- 关闭：快速模式。扫描时只计算 quickHash，新记录的 `文件指纹` 可能为空，适合先快速建立压缩包列表。

快速模式不会清空已有记录的完整文件指纹。需要补齐空指纹时，在设置页点击 `补全文件指纹`。

首页扫描和右键扫描完成后会显示扫描耗时和当前模式。

## Phase 51 补充：日志系统

日志目录位于设置页显示的 `日志目录`。当前会按用途写入：

- `app.log`：程序启动、退出、右键动作等通用事件。
- `error.log`：数据库、写库、自动学习等错误。
- `archive.log`：扫描和密码测试任务事件。
- `extract.log`：解压结果。
- `database.log`：数据库打开结果。

日志不会记录明文密码。诊断包会复制日志目录下的 `.log` 文件。

## Phase 51 补充：压缩包分类候选

首页压缩包表格新增 `分类` 列。选中一个或多个压缩包后点击 `设置分类`，输入分类名称即可保存；输入空值并确认可清空分类。

智能匹配候选顺序更新为：

1. 当前压缩包历史。
2. 同 fullHash 历史。
3. 同目录历史。
4. 同分类密码。
5. 密码库全局排序。
6. 同目录说明文件。

设置页 `智能匹配` 区域可关闭 `同分类密码候选`。

## Phase 52 补充：基础 UI 显示

程序固定使用 `Microsoft YaHei UI` 作为主要界面字体，表格数字单元格使用 `Segoe UI` 并右对齐。该调整用于避免部分 Windows 字体 fallback 导致数字看起来像符号，但复制后仍是正常数字的问题。

设置页智能匹配数字输入框使用 `Arial`。首页、密码库、历史记录、解压队列表格统一了行高、表头、网格线、交替行背景和选中颜色。列宽拖动、分页、复制和排序功能保持不变。

## Phase 53 补充：Widgets 现代化外观

程序统一了按钮、输入框、下拉框、数字输入框、复选框、卡片、状态栏和菜单的基础样式。设置页运行目录合并为一张信息卡，目录操作按钮放入独立操作卡，功能入口保持不变。

## Phase 54 补充：轻量 UI 路线

QML 试点已验证可行，但为降低发布包体积和运行时占用，当前版本回退 QML，继续使用纯 Qt Widgets。首页、设置页、密码库、历史记录和队列表格功能保持不变。

## Phase 55 补充：首页概览

首页顶部新增纯 Widgets 概览卡片，显示筛选压缩包数、当前页显示数、密码库记录数和待处理任务数。该功能不引入 QML，不增加 Qt Quick 运行依赖。
