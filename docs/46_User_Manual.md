# User Manual

## 启动

正式使用运行：

```text
out/PasswordManager-portable/PasswordManager.exe
```

用户数据保存在便携目录下的 `data/`，密码当前按已确认方案明文保存到本地 SQLite。

## 密码库

- `新增`：添加明文密码记录。
- `编辑`：修改选中的密码记录。
- `删除`：删除选中的密码记录。
- `复制单元格`：复制当前格，特别适合复制密码格。
- `复制整行`：复制当前行。
- `导入 CSV` / `导出 CSV`：使用 UTF-8 CSV，内容包含明文密码。

CSV 格式：

```text
password,category,note,favorite,success_count,failure_count
```

## 首页扫描与测试

- `扫描文件`：选择一个或多个压缩包。
- `扫描文件夹`：递归扫描文件夹。
- 支持 ZIP、RAR、7Z。
- `测试密码`：先输入密码，再测试选中压缩包。
- 密码框留空时，可确认后测试无密码压缩包。
- `智能匹配测试`：可多选压缩包，批量使用密码库候选和压缩包同目录说明文件候选进行测试。

## 表格

首页、密码库、历史记录、解压队列都支持：

- 空数据时保留表头。
- 列宽拖动调整。
- 点击表头排序，ID 按数字排序。
- 分页：10、20、50、100、200、500、全部。
- 输入页码跳转、上一页、下一页。

## 历史记录与解压

- 历史记录显示压缩包与成功密码的关联。
- 可复制密码、复制整行、查看对应密码库记录、删除历史关联。
- 删除历史不会删除密码库记录。
- 历史记录页内的 `解压` 会要求选择输出目录。

## Windows 资源管理器右键菜单

在 `设置` 中安装、卸载、刷新或 `重新安装/修复` 右键菜单。发布包移动位置后需要重新安装/修复。

压缩包右键：

```text
压缩包密码管理器 >
├── 自动查找密码
├── 使用密码库测试
├── 查看结果
├── 解压
├── 打包压缩包
└── 打开主程序
```

文件夹右键：

```text
压缩包密码管理器 >
├── 扫描文件夹
├── 打包压缩包
└── 打开主程序
```

行为说明：

- `自动查找密码`：只检查该压缩包是否已有成功密码记录，并弹窗提示；无密码压缩包会提示无需密码。
- `使用密码库测试`：打开或调出主程序，把密码库候选和压缩包同目录说明文件候选加入测试队列，不解压；无密码压缩包会跳过，不会记录任意密码。
- `查看结果`：不打开主界面，只弹窗显示该压缩包的成功密码记录，最多显示前 5 条。
- `解压`：默认解压到压缩包同目录的同名文件夹。程序先测试无密码，再测试已知密码，最后要求手动输入密码；测试通过后才真正解压。非空密码解压成功后会写入密码库和历史记录。
- `打包压缩包`：打开本项目内置 `tools/7zip/7zFM.exe`，由用户在 7-Zip 图形界面里选择压缩参数。

同一路径同名压缩包如果被重新创建，程序会通过 quickHash 判断内容是否变化。内容变化后会清理该路径旧压缩包的成功密码关联，避免旧密码显示到新压缩包上。
- `扫描文件夹`：打开主程序并扫描该文件夹。
- `打开主程序`：打开主窗口。

## 设置

- 查看运行目录、数据目录、日志目录、备份目录和内置 7-Zip 状态。
- 打开程序目录、数据目录、备份目录、日志目录、用户手册、测试数据。
- 备份或恢复 SQLite 数据库。
- 导出诊断包。
- 运行性能基准，当前仍是单线程基线；GPU / 多线程加速留作后续专题。

## 测试注意

- 不要直接双击 Debug 测试程序，例如 `PasswordManagerTests.exe`，否则可能弹出缺少 `Qt6Cored.dll`。自动化测试请用 CTest。
- 真实环境测试前建议先备份数据库。
- CSV 导出、数据库文件和诊断包都可能包含明文密码。
## Phase 38 补充：右键菜单覆盖范围

普通文件右键：

```text
压缩包密码管理器 >
└── 打包压缩包
```

文件夹空白处右键：

```text
压缩包密码管理器 >
├── 打包压缩包
└── 打开主程序
```

`打包压缩包` 调用发布目录内置 `tools/7zip/7zFM.exe`，发布包同时携带 `tools/7zip/Lang/zh-cn.txt`。卸载右键菜单会同时清理早期版本可能写入的历史 `PasswordManager` 注册表项；如果右键仍残留失效入口，先在设置页执行 `重新安装/修复`，再执行 `卸载右键菜单`。

## Phase 39 补充：普通文件打包

普通文件右键的 `打包压缩包` 会先进入 PasswordManager 的 `compress-archive` 动作，再打开该文件所在目录的内置 7-Zip File Manager。这样 txt、py、json 等普通文件不会被 7-Zip 误当作压缩包打开。文件夹和压缩包右键打包行为保持不变。

## Phase 40 补充：右键菜单卸载验证

卸载右键菜单后，程序会逐项反查当前和历史 `PasswordManager` 注册表路径。如果仍有残留，设置页会弹窗显示具体残留项；如果没有残留，才提示卸载完成。

## Phase 41 补充：状态刷新只读化

设置页刷新右键菜单状态时，Windows 下使用原生只读注册表查询，不再通过 `QSettings` 读取不存在的 key，避免卸载后又生成 `PasswordManager.*Menu` 空壳注册表项。

## Phase 42 补充：安装状态识别

设置页读取右键菜单状态时，会正确处理 `RegGetValueW()` 长度探测返回 `ERROR_MORE_DATA` 的情况，避免安装成功但状态仍显示未安装或不完整。

## Phase 43 补充：状态读取稳定化

设置页右键菜单状态读取改为先打开注册表 key，再用 `RegQueryValueExW()` 读取值，进一步避免安装后状态被误判为未安装或不完整。

## Phase 44 补充：7-Zip GUI 中文

主程序启动时会设置 `HKCU\Software\7-Zip\Lang = zh-cn`，并要求发布包中存在 `tools/7zip/Lang/zh-cn.txt`。右键打开内置 7-Zip File Manager 时应优先显示中文。

## Phase 45 补充：说明文件密码候选

智能匹配测试会读取压缩包同目录的说明文件作为额外候选来源。第一版只读取 `.txt`、`.md`、`.nfo`、`.url`，优先读取与压缩包同名的说明文件，也会读取文件名包含 `readme`、`password`、`pass`、`pwd`、`密码`、`说明`、`解压`、`提取` 的说明文件。

支持格式示例：

```text
解压密码：123456
密码: 123456
password = 123456
pwd: 123456
```

说明文件候选排在密码库候选之后，不会直接写入密码库。只有实际测试成功后，程序才会按现有成功流程记录密码。

## Phase 46 补充：智能匹配优先级

首页 `智能匹配测试` 和右键 `使用密码库测试` 使用同一套候选顺序：

1. 当前压缩包已知成功密码。
2. 同目录其他压缩包的已知成功密码。
3. 密码库候选，内部按收藏、成功次数、失败次数、更新时间和 ID 排序。
4. 压缩包同目录说明文件候选。

重复密码只保留最靠前来源的一条。分类候选暂未启用，因为压缩包记录当前没有分类字段。
