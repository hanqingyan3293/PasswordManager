# Phase 4 Plan: Bundled 7-Zip Password Test

状态：执行中

## 1. 目标

接入内置 `tools/7zip/7z.exe`，实现单个压缩包的密码测试。

## 2. 本阶段要做

- 固定调用 exe 相对目录下的 `tools/7zip/7z.exe`。
- 使用 `7z t -pPASSWORD ARCHIVE` 测试压缩包。
- 区分成功、密码错误、压缩包损坏、超时、7-Zip 缺失、进程错误。
- 首页支持对选中压缩包输入密码并测试。
- 使用真实压缩包做自动化测试。

## 3. 测试资源要求

测试压缩包固定放在：

```text
testdata/archives/
```

生成过程和临时文件固定放在：

```text
testdata/tmp/
```

压缩包大小控制在 1-10KB。

## 4. 本阶段不做

- 不做多线程任务队列。
- 不做批量密码测试。
- 不做智能密码匹配。
- 不做历史关联保存。
- 不做解压。
- 不做右键菜单。
- 不做 GPU 加速。

## 5. 验收标准

- CMake 配置成功。
- Ninja 编译成功。
- 测试压缩包真实生成。
- 正确密码返回成功。
- 错误密码返回密码错误。
- 缺失 7-Zip 返回缺失状态。
- 程序能启动和关闭。
