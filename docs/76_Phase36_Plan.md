# Phase 36 Plan - Context Menu Corrections

## 目标

修复右键菜单真实测试中发现的问题：

- `打包压缩包` 不应直接生成 `.7z`，应打开 7-Zip 图形界面供用户选择。
- 无密码压缩包不应把密码库里的任意密码都记为正确密码。
- `自动查找密码` 和 `查看结果` 弹窗不能无限列出所有密码。
- 已有主程序窗口时，`使用密码库测试` 和 `打开主程序` 应复用已有窗口。
- 右键 `解压` 应先验证密码再解压，避免文件已解出但程序最后提示失败。

## 实施方案

1. 补入 `tools/7zip/7zFM.exe`。
2. `打包压缩包` 改为打开 `7zFM.exe <选中路径>`。
3. `SevenZipRunner` 对非空密码先做空密码预检：
   - 空密码成功：返回 `NoPasswordRequired`。
   - 空密码错误：继续测试用户密码或候选密码。
4. `PasswordTestTaskManager` 对无密码压缩包的非空密码任务直接标记为 `NoPasswordRequired`，不保留候选密码。
5. 首页和右键批量密码库测试在入队前跳过无密码压缩包。
6. 密码成功回写只接受 `Completed + Success + 非空密码`。
7. 右键解压改为：
   - 先空密码测试。
   - 再已知密码测试。
   - 再手动输入密码测试。
   - 测试通过后才真正解压。
8. 增加本地单实例 IPC：
   - 已有窗口时，新进程把 `open-main`、`use-password-library-test`、`scan-folder` 转发给旧窗口后退出。

## 验收

- 无密码压缩包不会产生任意密码成功记录。
- `查看结果` 弹窗最多显示前 5 条密码。
- 右键 `打包压缩包` 打开 7-Zip 文件管理器。
- 已打开主程序时，右键测试和打开主程序不再新开窗口。
- Debug / Release 测试通过。
