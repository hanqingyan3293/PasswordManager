# Phase 2 Plan: SQLite and Password Library

状态：已确认，执行中

## 1. 已锁定决策

密码存储策略：明文 SQLite，不加密。

风险：
- 数据库文件泄露即密码泄露。
- 日志、导出、备份不能默认记录或复制到不受控位置。
- 后续如果改为加密，需要做数据库迁移。

## 2. 目标

实现基础密码库闭环：

- SQLite 数据库初始化。
- 数据库版本表。
- 密码表。
- 密码新增、编辑、删除、搜索。
- 收藏、分类、成功次数、失败次数字段。
- 程序重启后数据保留。

## 3. 本阶段要做

1. 数据库服务
   - 打开 `data/passwordmanager.sqlite3`。
   - 建立 `database_info`。
   - 建立 `passwords`。
   - 执行基础迁移。

2. 密码仓库
   - `listPasswords(filter)`。
   - `addPassword(record)`。
   - `updatePassword(record)`。
   - `deletePassword(id)`。

3. 密码库页面
   - 表格显示密码、分类、收藏、成功次数、失败次数、备注、更新时间。
   - 搜索框。
   - 新增按钮。
   - 编辑按钮。
   - 删除按钮。
   - 刷新按钮。

4. 文档
   - 记录明文存储风险。
   - 记录 Phase 2 验证结果。

## 4. 本阶段不做

- 不做密码加密。
- 不做 JSON 导入导出。
- 不做压缩包扫描。
- 不做 7-Zip 密码测试。
- 不做历史关联保存。
- 不做解压。
- 不做右键菜单。
- 不做 GPU 加速。

## 5. 验收标准

- CMake 配置成功。
- Ninja 编译成功。
- 程序能启动和关闭。
- 首次启动会创建 `data/passwordmanager.sqlite3`。
- 密码库可新增记录。
- 密码库可编辑记录。
- 密码库可删除记录。
- 密码库可搜索记录。
- 重启程序后密码记录仍存在。
