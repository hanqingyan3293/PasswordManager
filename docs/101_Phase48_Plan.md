# Phase 48 Plan - Full Hash File Fingerprint

## 目标

在现有 `quickHash` 基础上新增完整文件 SHA256 指纹，用于更可靠地识别压缩包内容，并支持不同路径下同一压缩包复用成功密码历史。

## 范围

- `archives` 表新增 `full_hash` 字段。
- 扫描压缩包时计算完整 SHA256。
- 旧数据库启动时自动迁移新增字段。
- 同路径压缩包变化判断优先使用 `full_hash`，旧记录没有完整哈希时回退 `quick_hash`。
- 智能匹配新增同 `full_hash` 历史候选层。

## 候选优先级调整

1. 当前压缩包已知成功密码。
2. 同 fullHash 的其他路径成功密码。
3. 同目录其他压缩包成功密码。
4. 密码库候选。
5. 同目录说明文件候选。

## 不做

- 不移除 `quickHash`。
- 不做多线程/GPU 加速。
- 不做后台补全所有旧记录 fullHash。
- 不改变发布版本号。
