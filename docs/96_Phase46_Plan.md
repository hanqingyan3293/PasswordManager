# Phase 46 Plan - Candidate Priority Formalization

## 目标

把智能匹配的候选密码来源从单一密码库排序升级为可维护的分层优先级，避免后续加入新来源时顺序混乱。

## 本阶段优先级

1. 当前压缩包已知成功密码。
2. 同目录其他压缩包的已知成功密码。
3. 收藏密码。
4. 高成功次数、低失败次数、最近更新的密码库记录。
5. 普通密码库记录。
6. 压缩包同目录说明文件候选。

## 不做

- 不新增数据库字段。
- 不实现分类候选：当前压缩包没有分类元数据，无法稳定判断“同分类”。
- 不实现 GPU 或多线程加速。
- 不改变右键菜单结构。

## 验收标准

- 首页智能匹配和右键 `使用密码库测试` 使用同一套分层顺序。
- 候选去重，靠前来源优先。
- 当前压缩包成功历史优先于同目录历史和密码库。
- 说明文件候选排在密码库之后。
- 单元测试覆盖顺序和精确历史查询。
