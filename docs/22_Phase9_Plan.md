# Phase 9 Plan: Windows Shell Integration

状态：执行中

## 1. 目标

实现 Windows 资源管理器右键菜单安装/卸载入口。

## 2. 本阶段要做

- 使用 HKCU 当前用户注册表，不要求管理员权限。
- 支持 `.zip`、`.rar`、`.7z`。
- 设置页显示右键菜单安装状态。
- 设置页提供安装和卸载按钮。
- 注册表操作前二次确认。
- 菜单包含：
  - 添加测试队列。
  - 查看结果。

## 3. 本阶段不做

- 不做管理员级 HKLM 注册表。
- 不做所有功能子菜单。
- 不做复杂 ExplorerCommand COM 扩展。
- 不做右键菜单直接批量解压。
- 不做图标资源注册。

## 4. 验收标准

- CMake 配置成功。
- Ninja 编译成功。
- 自动化测试通过。
- 程序能启动和关闭。
- 设置页有右键菜单状态、安装、卸载入口。
- 自动化测试不真实写注册表。
