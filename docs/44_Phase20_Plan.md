# Phase 20 Plan - Stabilization And Documentation

## Goal

Stabilize the project before real-environment testing by consolidating documentation and clarifying the current user workflows.

## Scope

- Add a current feature overview.
- Add a user operation manual.
- Update README status and next-phase order.
- Keep release data intact for real-environment testing.

## Out Of Scope

- Deleting user or manual-test data.
- Changing database schema.
- Changing plaintext password storage.
- GPU or multi-threaded acceleration.
- New user-facing behavior.

## Acceptance

- Current features are documented in one place.
- Manual testing has a stable workflow reference.
- README points to the new documents.
- Existing automated tests continue to pass.
