# Phase 3 Plan: Archive Scanning

状态：执行中

## 1. 目标

实现本地压缩包扫描和归档元数据保存，为后续 7-Zip 密码测试准备输入。

## 2. 本阶段要做

- 单文件扫描。
- 多文件扫描。
- 文件夹递归扫描。
- ZIP/RAR/7Z 后缀识别。
- 保存路径、文件名、扩展名、大小、修改时间、快速 Hash。
- 首页显示扫描结果表。
- 扫描结果写入 SQLite `archives` 表。

## 3. 本阶段不做

- 不做完整 Hash。
- 不做 7-Zip 密码测试。
- 不做密码匹配。
- 不做历史关联保存。
- 不做解压。
- 不做右键菜单。
- 不做 GPU 加速。

## 4. 快速 Hash 策略

快速 Hash 使用 SHA-256，但不读取整个文件：

- 文件大小小于等于 2 MiB：读取全文件。
- 文件大于 2 MiB：读取文件头 1 MiB 和文件尾 1 MiB，并混入文件大小。

这不是完整内容校验，只用于快速识别候选文件。完整 Hash 后续作为可选功能。

## 5. 验收标准

- CMake 配置成功。
- Ninja 编译成功。
- 程序能启动和关闭。
- 能选择单个 ZIP/RAR/7Z 文件并加入列表。
- 能选择多个 ZIP/RAR/7Z 文件并加入列表。
- 能选择文件夹递归扫描支持格式。
- 非支持格式被跳过。
- 扫描结果写入 `archives` 表。
- 重启程序后扫描记录仍可显示。
