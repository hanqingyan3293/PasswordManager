# Phase 52 Report：UI 基础修复

## 已完成

- 新增 `UiStyle`，集中管理应用字体和表格基础样式。
- 主程序启动后固定全局字体为 `Microsoft YaHei UI`。
- 首页、密码库、历史记录、解压队列表格统一使用 `Microsoft YaHei UI`。
- 数字单元格使用 `Segoe UI` 并右对齐，降低数字被系统字体 fallback 渲染成异常符号的风险。
- 设置页智能匹配数字输入框使用 `Arial`，修复该区域数字显示不一致的问题。
- 统一表格行高、表头颜色、网格线、交替行背景和选中颜色。
- 表格列宽模式统一为 `Interactive`，保留列之间的双向箭头拖动调整。
- 保留现有分页、排序、复制、列宽拖动和选择行为。
