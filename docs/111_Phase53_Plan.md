# Phase53 Widgets 现代化外观计划

日期：2026-08-02

目标：在不引入 QML、不改变现有业务行为的前提下，统一 Qt Widgets 外观，并先压缩设置页的信息密度。

## 范围

- 全局统一按钮、输入框、下拉框、数字输入框、复选框、卡片、状态栏、菜单的基础样式。
- 主窗口左侧导航栏改为更克制的浅色选中态。
- 设置页运行目录由多张单行卡片合并为一张信息卡，减少纵向拥挤。
- 保留 Phase52 的数字字体修复，设置页智能匹配数字输入继续使用 Arial。

## 不做

- 不迁移 QML。
- 不改右键菜单注册表逻辑。
- 不改数据库结构。
- 不改压缩包测试、解压、智能匹配业务逻辑。

## 验收

- Debug/Release 能正常编译。
- CTest 全部通过。
- 发布包能重新生成。
- 设置页功能按钮仍能点击，状态显示仍能刷新。
