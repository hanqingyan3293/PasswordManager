# Phase 6 Plan: Password Matching

状态：执行中

## 1. 目标

从密码库生成候选密码，并按优先级加入测试任务队列。

## 2. 本阶段要做

- 新增密码匹配器。
- 从密码库读取候选密码。
- 过滤空密码。
- 去重。
- 排序：
  1. 收藏密码优先。
  2. 成功次数高优先。
  3. 失败次数低优先。
  4. 更新时间新优先。
  5. ID 大优先。
- 首页新增“智能匹配测试”。
- 为选中压缩包批量创建 WAITING 测试任务。

## 3. 本阶段不做

- 不做精确历史成功密码。
- 不做文件指纹历史密码。
- 不做同目录/同资源组密码。
- 不做说明文件提取密码。
- 不做任务成功后的历史关联保存。
- 不做解压。
- 不做右键菜单。
- 不做 GPU 加速。

## 4. 验收标准

- CMake 配置成功。
- Ninja 编译成功。
- 自动化测试通过。
- 程序能启动和关闭。
- 匹配器能按优先级排序。
- 匹配器能去重并过滤空密码。
- 首页能将候选密码加入任务队列。
