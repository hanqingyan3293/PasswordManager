# Phase 50 Plan：扫描性能与文件指纹模式

## 目标

大目录或大文件扫描时，允许用户在完整指纹准确性和扫描速度之间选择。

## 范围

- 设置页新增 `扫描时计算完整文件指纹`。
- 默认开启，保持现有精确扫描行为。
- 关闭后进入快速扫描模式：扫描时只计算 quickHash，不计算 fullHash。
- 扫描完成提示显示耗时和当前模式。
- 快速扫描不能清空已有记录的 fullHash。
- 旧记录或快速扫描产生的空 fullHash，可继续使用 `补全文件指纹` 补齐。

## 不做

- 不做多线程扫描。
- 不做 GPU 加速。
- 不改变智能匹配候选顺序。
- 不改变数据库字段结构。

## 验收

- 默认设置下扫描仍会写入完整 SHA256。
- 关闭开关后新扫描记录允许 fullHash 为空。
- 关闭开关后重复扫描已有完整指纹记录，不会把 fullHash 覆盖为空。
- 首页和右键扫描反馈能看到耗时和精确/快速模式。
- 单元测试、Release 打包和 ZIP 校验通过。
