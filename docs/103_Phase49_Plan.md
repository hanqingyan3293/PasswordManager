# Phase 49 Plan - Full Hash Backfill Tool

## 目标

为旧数据库中的压缩包记录补全 `full_hash`，让 Phase 48 的同 fullHash 跨路径历史候选能覆盖旧记录。

## 范围

- 设置页新增 `补全文件指纹` 按钮。
- 只处理 `full_hash` 为空的压缩包记录。
- 文件存在时计算完整 SHA256 并写回 `archives.full_hash`。
- 文件不存在时只计数，不删除记录。
- 计算失败或写库失败时只计数并显示最后错误。

## 不做

- 不修改密码库。
- 不修改成功历史记录。
- 不删除不存在的压缩包记录。
- 不做后台线程、进度条或取消按钮。
- 不做 GPU / 多线程加速。
