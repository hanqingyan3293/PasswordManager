# Phase 51 Plan：日志系统完善与分类候选

## 目标

补齐项目规格书中的分层日志文件，并让智能匹配支持“同分类密码候选”。

## 范围

### 日志系统

- 扩展 `AppLogger`，固定支持：
  - `app.log`
  - `error.log`
  - `archive.log`
  - `extract.log`
  - `database.log`
- 补关键日志点：
  - 程序启动、退出、右键动作入口和结果。
  - 数据库打开、迁移失败。
  - 扫描开始、结束、保存数量、跳过数量、耗时和扫描模式。
  - 密码测试任务入队、运行、完成、取消、超时。
  - 解压动作结果。
- 日志不记录明文密码。

### 分类候选

- `archives` 表新增 `category` 字段，旧库自动迁移。
- `ArchiveRecord` 新增 `category`。
- 首页表格显示压缩包分类。
- 首页提供设置选中压缩包分类的入口。
- 设置页新增 `同分类密码候选` 开关。
- 智能匹配新增同分类密码候选层。
- 候选顺序：
  1. 当前压缩包历史。
  2. 同 fullHash 历史。
  3. 同目录历史。
  4. 同分类密码。
  5. 密码库全局排序。
  6. 同目录说明文件。

## 不做

- 不做自动分类。
- 不做 AI 分类。
- 不做复杂多标签。
- 不做分类管理独立页面。
- 不把明文密码写入日志。
- 不改变密码明文保存策略。

## 验收

- 旧数据库启动后自动拥有 `archives.category`。
- 压缩包分类可在首页设置并保存。
- 分类候选排在同目录历史之后、全局密码库之前。
- 关闭 `同分类密码候选` 后不使用该层。
- 日志目录能生成并导出 5 类日志文件。
- 构建、单元测试、Release 打包和 ZIP 校验通过。
