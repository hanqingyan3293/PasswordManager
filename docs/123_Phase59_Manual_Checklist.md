## 7-Zip 与压缩包

- [ ] 打开内置 7-Zip File Manager，界面显示中文。
- [ ] 扫描自动生成的 `AcceptanceData-中文-Unicode` 文件夹，可看到 3 个压缩包。
- [ ] `no-password.7z` 可以作为无密码压缩包正常测试和解压。
- [ ] `password-1234.7z` 输入 `1234` 测试成功，输入错误密码失败。
- [ ] `password-5678.zip` 输入 `5678` 测试成功。
- [ ] 正确密码测试成功后自动写入密码库，错误密码不写入。
- [ ] 智能匹配可以使用已记录密码，但不会把密码库所有密码误判为正确密码。
- [ ] 解压默认进入同名文件夹，文件内容正确。
- [ ] `打包压缩包` 可以打开内置 7-Zip GUI，并允许用户选择参数。
