# Acceptance Checklist

版本：v0.1
状态：验收清单草案

## 1. MVP 完成标准

MVP 必须完成：
- Qt 程序框架。
- SQLite 数据库。
- 密码库。
- ZIP/RAR/7Z 识别。
- 内置 7-Zip 密码测试。
- 历史关联保存。
- 基础解压。

MVP 明确不做：
- 自动批量解压。
- 账号系统。
- 网络同步。
- AI 密码解析。
- GPU 加速。
- 完整插件系统。
- 高级动画。

## 2. 安全验收

| 项目 | 验收标准 |
| --- | --- |
| 网络 | 程序不主动联网 |
| 原始文件 | 不修改用户原始压缩包 |
| 日志 | 日志默认不明文记录密码 |
| 解压 | 成功测试后必须等待用户确认 |
| 7-Zip | 只调用项目目录内的 `tools/7zip/7z.exe` |
| 数据库 | 数据库文件位置明确，可备份 |

## 3. 功能验收

| 功能 | 验收标准 |
| --- | --- |
| 密码库 | 可新增、编辑、删除、搜索 |
| 分类 | 密码可绑定分类 |
| 收藏 | 收藏密码优先级高于普通密码 |
| 文件扫描 | ZIP/RAR/7Z 能识别，其他格式跳过 |
| 密码测试 | 能区分成功、失败、超时、压缩包损坏 |
| 历史关联 | 成功密码与压缩包记录可保存 |
| 解压 | 用户确认后可解压到指定目录 |
| 说明文件候选 | 可从压缩包同目录说明文件提取明确格式密码，且不直接写入密码库 |
| 智能匹配优先级 | 当前压缩包历史优先于同目录历史、密码库和说明文件候选 |
| 功能级设置 | 智能匹配来源和右键菜单功能项可保存并按规则生效 |
| 文件指纹 | 扫描记录完整 SHA256，并支持同 fullHash 历史候选 |
| 指纹补全 | 可为旧记录补全 fullHash，且不删除或修改密码历史 |
| 扫描模式 | 可选择精确扫描或快速扫描，快速扫描不清空已有 fullHash |
| 压缩包分类 | 可给压缩包设置分类，并用于同分类密码候选 |
| 日志系统 | app/error/archive/extract/database 分层日志可生成并进入诊断包 |

## 4. 性能验收

第一版只要求：
- UI 不因单个测试任务卡死。
- 扫描大量文件时能显示进度。
- 任务可取消。

后期再设定：
- 多线程并发数。
- 大目录扫描性能。
- Hash 计算性能。
- GPU 加速可行性指标。

## 5. 发布验收

| 项目 | 验收标准 |
| --- | --- |
| 绿色便携 | 解压目录即可运行 |
| 依赖完整 | 发布包包含 Qt 运行库和内置 7-Zip |
| 数据目录 | `data/config/logs/backup` 路径明确 |
| 新机器测试 | 无 Qt、无 7-Zip 的机器上仍可运行 |
